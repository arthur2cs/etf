# Instructions pour Claude

- **Ne jamais lancer d'émulateur** (Android ou autre) pour tester l'appli.
  Les émulateurs sont gourmands en performance et en espace disque. Si un
  test sur appareil est nécessaire, l'utilisateur le fait lui-même sur son
  device réel. Se limiter à `flutter analyze`, `flutter test` et
  `flutter build` pour vérifier que le code compile.
